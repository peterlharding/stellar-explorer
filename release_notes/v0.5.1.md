# Stellar Explorer 0.5.1

The app now carries its own name throughout, rather than that of the spike it grew from.
Nothing changes in how it looks or works, apart from its name on the Vision Pro.

## Changed

- **"Stellar Explorer" under its icon** (Vision Pro): the Home View names the app "Stellar Explorer", with a space.
- **A new bundle id** (Vision Pro): the app is `io.github.peterlharding.StellarExplorer`, so it installs beside the old StellarSpike app rather than over it.
  Delete the old app from the headset; the new one asks again for the microphone, speech recognition, hand tracking and local network.
- **The spike's name is gone** (all platforms): the Unreal module and targets are `StellarExplorer` and `StellarExplorerEditor`, the source is in `src/app/Source/StellarExplorer`, and `spike.sh` is now `stellar.sh`, with the same verbs.
  The Mac app's log is in `~/Library/Logs/StellarExplorer`.

## Data

- No change: the catalogue is the same as in 0.5.0, schema 1, and need not be rebuilt.
- There is no `user.sqlite` yet.

## Under the hood

- After pulling, delete `src/app/Intermediate` and `src/app/Binaries` before building: they refer to the old module name.
- The core library is unchanged, at interface version 7, and need not be rebuilt.
- The full list is in the [changelog](https://github.com/peterlharding/stellar-explorer/blob/v0.5.1/CHANGELOG.md).

## Not tested

- The rename was built on Windows and on the Mac, and run in the Vision Pro on 8 November 2026; it was not run on the Mac's desktop or the Vive. This release's own build, differing only in its version, was packaged for the Vision Pro but not run in it.
- The headset frame rates have not been measured against the full star budget for this release.
