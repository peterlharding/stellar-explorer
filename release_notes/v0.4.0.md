# Stellar Explorer 0.4.0

Retrace your steps: "Stellar, backtrack" takes you back to where your last journey began, and again to the one before, like a browser's Back button.

## Highlights

- **Backtrack by voice** (Mac and Vision Pro): "Stellar, backtrack", or "go back", "take me back" or "undo", returns to where the last journey began, with the star you had kept then kept again.
  Said again, it goes back one more journey, for up to 50 of them; each answer says how many steps remain, as in "Back to Vega; 2 more back".
  Journeys are "go to", "go there", "back off", "closer" and "return to the Sun", whether by voice, the menus or the console.
- **Backtrack from the desk** (Mac): the console has a Backtrack button, which works on the Mac's own app or on a Vision Pro steered from it.

## Data

- No change: the catalogue is the same as in 0.3.0, schema 1, and need not be rebuilt.
- There is no `user.sqlite` yet.

## Under the hood

- The engine-independent C++ core is at interface version 7, for the new voice command. Rebuild the core libraries after pulling: `scripts/make_macos.sh` on a Mac, and `build-msvc` on Windows. The app quits with an error on a stale build.
- The full list is in the [changelog](https://github.com/peterlharding/stellar-explorer/blob/v0.4.0/CHANGELOG.md).

## Known limits

- Moves made with the mouse on the desktop are not yet recorded, so backtrack skips over them.
- In the headset backtrack is by voice only; there is no button for it on the hand menu.

## Not tested

- Tested on the Mac and in the Vision Pro on 5 and 6 November 2026. This release's own build, differing only in its version, was packaged for the Vision Pro but not run in it.
- Windows and the Vive were not built or run for this release. The Windows core library must be rebuilt for interface version 7 before the app will start there.
- The headset frame rates have not been measured against the full star budget for this release.
