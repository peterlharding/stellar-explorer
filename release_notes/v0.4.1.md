# Stellar Explorer 0.4.1

A build fix so that 0.4.0 compiles on Windows. Everything 0.4.0 can do is unchanged; this release simply lets the Vive build be made from the released source.

## Highlights

- **The Windows build works again.** The 0.4.0 source built on the Mac but not on Windows, so the Vive build could not be made from it without a local fix. It now builds as released.
- Nothing you see or do in the app changes, on any platform.

## Fixed

- On Windows the app would not compile: two names in the desktop console clashed with the engine's own, and a voice command was read before it was set. Harmless on the Mac, which compiles the same code, but fatal on Windows, where the build treats such warnings as errors.

## Data

- No change: the catalogue is the same as in 0.4.0, schema 1, and need not be rebuilt.

## Under the hood

- The core is unchanged, at interface version 7; the fix is in the app's source only, and corrects code that MSVC rejects and Clang accepts.
- The full list is in the [changelog](https://github.com/peterlharding/stellar-explorer/blob/v0.4.1/CHANGELOG.md).

## Not tested

- The Windows build was confirmed to compile cleanly and the core's tests pass there; it was not run in the Vive for this release, and the headset frame rate was not measured against the full star budget.
- The Mac and Vision Pro builds were not rebuilt or run for this release. The fix does not touch their code paths, and they already built from the 0.4.0 source.
